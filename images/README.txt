ATHENA WEBSITE - PHOTO INSTRUCTIONS

Put the client's photos inside this images folder.

HOME PHOTO
Use: images/hero.jpg
Open index.html. Find PHOTO PLACEHOLDER and replace the placeholder with:
<img src="images/hero.jpg" alt="Athena Aesthetician">

ABOUT PHOTO
Use: images/about.jpg
Open about.html. Find PHOTO PLACEHOLDER and replace the placeholder with:
<img src="images/about.jpg" alt="Athena Aesthetician">

TRANSFORMATION PHOTOS
Use these exact filenames:
images/before-1.jpg
images/after-1.jpg
The transformations page already points to these files. The images automatically switch every 2.5 seconds.

FACEBOOK
Open contact.html. Find the FACEBOOK LINK comment and replace href="#" with the client's real Facebook URL.
Example: href="https://www.facebook.com/yourpage"

IMPORTANT
The filename in the HTML must exactly match the filename in this folder.
You can use .jpg, .jpeg, .png, or .webp.
